Brief: `../uo-docx.md`, "D1b — writer (architecture)", "Emitter frontiers". One table per kind, each row

## 2. Regex sites and their matcher (dynamic ones through a core template, named)

Every site is a hand matcher in `object.rs` (linear, exact on any text; the private functions of
serialize.ts are copied verbatim into `js/regex-sites/w2.mjs` and compared on 709 inputs: 109 hand-written
edge cases and 600 seeded tag soups). No dynamic regex (no `new RegExp` in these functions): the
`XmlPatch.setAttrs` per-attribute regex is W6's.

| Site (TS) | Pattern | Rust |
|---|---|---|
| serialize.ts:131 | `/<wp:extent\b[^>]*\/>/` (first), then `/cx="\d+"/`, `/cy="\d+"/` (first) on the match | `self_closing_tag_from` (memoised `>` scan), `replace_first_digit_attr` |
| serialize.ts:133 | `/<a:ext\b[^>]*\/>/g` | `self_closing_tag_from` loop |
| serialize.ts:137–138, 143–144 | `/<wp:positionH\b[^>]*>[\s\S]*?<\/wp:positionH>/` (and `V`), `/(<wp:posOffset>)-?\d+(<\/wp:posOffset>)/` (first) | `replace_pos_offset`, `replace_pos_offset_in` |
| serialize.ts:154, 213 | `/r:embed="uw:media"/g`, `"uw:layer"` (function replacement per occurrence) | `replace_embed_marks` (literal needle, one callback per occurrence) |
| serialize.ts:154 (`includes`), 319–322 | `r:embed="uw:fill"` replaced by a fixed rel id | `str::contains`, `str::replace` (literal) |
| serialize.ts:254 | `/<wp:docPr\b[^>]*\bname="([^"]*)"/` (greedy `[^>]*`: the last `name`) | `doc_pr_name` over `doc_pr_greedy` |
| serialize.ts:336 | `/<w:drawing\b[\s\S]*?<\/w:drawing>/` (first, function replacement) | `replace_first_drawing` |
| serialize.ts:337 | `/<mc:AlternateContent\b/` | `has_alternate_content` |
| serialize.ts:339 | `/<wp:docPr\b[^>]*\bhidden="1"/` | `has_doc_pr_hidden` (`doc_pr_greedy`) |
| serialize.ts:340–341 | `/\brelativeHeight="(\d+)"/`, `/\bbehindDoc="1"/` | `relative_height_of`, `has_behind_doc` |
| serialize.ts:344 | `/<v:group\b[^>]*>/` (first, function replacement) | `retag_v_group` |
| serialize.ts:346–347 | `/\sid="[^"]*"/` (test and replace), `/^<v:group/` | `find_id_attr`, `strip_prefix` |
| serialize.ts:349 | `/style="([^"]*)"/` (first; matches `mso-style="…"` too) | `retag` |
| serialize.ts:350 | `/;?visibility:[^;]*/g` | `remove_visibility` |
| serialize.ts:353 | `/z-index:-?\d+/` (first) | `replace_z_index` |
| serialize.ts:356 | `/^;/` | `strip_prefix` |
| serialize.ts:436 | `/(<wp:docPr\b[^>]*?\bid=")\d+"/g` (lazy `[^>]*?`: the first `id`) | `fresh_ids_text` |
| serialize.ts:437 | `/\s(?:wp14:anchorId\|wp14:editId\|o:spid)="[^"]*"/g` | `remove_anchor_attrs` |
| serialize.ts:251 | `/^<mc:Fallback>/`, `/<\/mc:Fallback>$/` | `strip_fallback` |
| shape-xml.ts:603 | `/<w:txbxContent\b[^>]*>([\s\S]*?)<\/w:txbxContent>/` | `txbx_content_of` |

Quadratic in V8, linear here: the lazy and greedy `[^>]*` of `docPrName`/`hidden`/`freshDrawingIds` try every
`<wp:docPr` candidate against the rest of the text. The regions of candidates that end at the same `>` nest,
so a region without a match is scanned once and the candidates inside it are skipped (`failed_end`):
`nopanic_w2.rs` has 100,000 `<wp:docPr id="x" ` without a `>` through it in 0.1 s (the first version of
`fresh_ids_text` took 122 s on 40,000, found by that test, fixed before the record).

## 8. Evaluation order around `revisionAttrs` / `mediaRelId` / `linkRelId`

W2 has no `revisionAttrs` and no `linkRelId` of its own (the revision ids and hyperlinks of a box's content
are numbered inside `txbx_inner`, the core's, in call order). `mediaRelId` and the counters, in the order
the TS evaluates them:

| Function | Order |
|---|---|
| `drawingXml` | `++drawingId`; push the image into `mediaOut`; build the text |
| `oleObjectXml` | `++drawingId`; push the image, then the OLE package; build the text |
| `pictureXml` | `patchDrawingGeometry`; then **one `mediaRelId` call per** `r:embed="uw:media"` occurrence, in order (outside the lossless save each call is a new `++drawingId` and a new `mediaOut` entry); then, if `img.layer`, one call per `uw:layer` occurrence with the `hdphoto` relationship for `wdp` |
| `fillMedia` | one `mediaRelId` call (not per occurrence), only when the text holds `r:embed="uw:fill"` and the style has a picture |
| `editedShapeXml` (box) | `txbxInner(tb)` (unless linked) → `fillMedia` → `patchDrawingGeometry` → `drawingWithParas` (**a second `txbxInner`**: revision ids, claimed sources, nested `o:spid` and image ids advance between the two) → `chainNext.get` → `++vmlSpid` → `shapeOut` |
| `editedShapeXml` (shape) | `fillMedia` → `++vmlSpid` → `shapeOut` |
| `onceShape` | the object is added to `emittedShapes` when first written; a repeat goes through `freshDrawingIds` |
| `freshDrawingIds` | the counter increments once per matched `wp:docPr`, in text order |
| `objectXml` (core, calls W2) | unchanged: `rPrXml` first, then the object functions |
