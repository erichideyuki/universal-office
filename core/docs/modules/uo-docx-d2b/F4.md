## Key orders built (U6)

`sp.type/vAlign/lnNumType/cols/titlePg/pgNumFmt/…` are `obj::set`/`delete`/`set_undefined` (a new key goes last; `sp.cols = undefined` is
a key holding `undefined`); the break `{ sectPr, headerRefs, footerRefs, raw?, id }`; the effective `sect.lnNumType` is
copied in the key order of `sp.lnNumType` (`{ ...sp.lnNumType }`); `colDefs` then `equalWidth`; `PageFill` literals
(`gradientGeometry` per style, then `color`, `color2`, `method`/`colors`); `PageBackground` `{ color, themeColor,
themeTint|themeShade }`. The two key orders of the hyphenation settings are kept because the TS compares
`JSON.stringify(next) === JSON.stringify(cur)`: `{ auto, caps, zone, limit }` from the file and `{ auto, caps, limit,
zone }` once edited, so an edit that changes nothing can still take a step when a zone is set (replicated, F4-D11).
The remainder: the run source of a watermark `RunSource { rPr, obj }` (`store.runs.set(id, { rPr, obj })`); the watermark run's props
`{ ...run.props, src }` (`src` last); the runs of Current Position `{ text, props, field }`; `HfRefEdit { kind, type, rid }` of the headers a
watermark creates (as `setLinkToPrevious`); `sectionSectPr(m, 0).titlePg = true` of the cover (a new key goes last); the preview `sectPr` of the
watermark, in the TS literal's order (`pageWidthTwips`, `pageHeightTwips`, the four margins, the two distances).

## Events (in the order the TS dispatches them)

`hfSectionOp`: `uw-change` (snapshot), then `uw-hfmode` `{active}` after the return to the page (none for the silent
exit); the new part of an `enterHeaderFooter` inside it adds `uw-styles-change` (the style entering `styles.xml`) and
`uw-dirty-change` when it changes; `setLineNumbering*`/`setPageSetup` with numbers on: `uw-styles-change` for the
`Nmerodelinha` style (outside a step); undo/redo with the layout's answer may add the same.
The remainder: `setWatermark`/`removeWatermark`: `uw-change` (+ `uw-dirty-change`), `uw-styles-change` when a header they create enters the
style, and NO `uw-hfmode` on the return to the edit (`enterHeaderFooter(…, true)` is silent). `insertHeaderFooterTemplate`: `uw-hfmode` `{active}` of
the entry (`active: false` when the part cannot be entered), then `uw-styles-change` (the Header/Footer style), then `uw-change`. `insertCoverPage`/
`removeCoverPage`: `uw-change` (+ `uw-dirty-change`). Current Position: `uw-change`.
