## The matcher (`find/regex.rs`)

The TS turns the Find box into a JavaScript `RegExp` source and runs it with `gu` or `giu`. Rust builds the same source and
runs it through its own engine:

- **Parser**: ES2025 Unicode-mode patterns over the code points of the source, for the constructs the builder can emit,
  with V8's error messages and order ("Invalid escape" for the `\-` a plain `e-mail` becomes, "Unterminated group" for the
  broken groups of `(@)`, "Range out of order in character class" when a surrogate pair of the class pairs up, "Too many
  captures", …); a construct the builder never emits answers `Unsupported` (never seen in the captures). Iterative (an
  explicit frame stack): any nesting parses and compiles.
- **Matcher**: a backtracking machine with the ES semantics — `RepeatMatcher` (the empty check of the optional iterations,
  the capture reset of each iteration), atomic lookarounds, lookbehind compiled backwards, `u`-mode reading by code points,
  V8's step back when `lastIndex` falls inside a surrogate pair (and so V8's endless loop of empty matches before an astral
  character, which the budget ends) — on an explicit stack (choice points and an undo trail); a quantified body that can
  only match empty runs once or not at all (the ES result; what V8 does).
- **Case** (`i`): `fold.rs`, the 1,479 classes of V8's `/iu` equivalence, generated from V8 itself
  (`js/gen-d2b-f9-fold.mjs`: candidates from the case mappings, every pair confirmed with a V8 `RegExp`; `ı`/`I` are linked
  by `toUpperCase` but do not match, `ſ`/`s` and U+0345/`ι` do); a class matches when a member of the character's class is in
  it, a negated class when none is (V8 closes over case before complementing: `/[^\p{L}]/iu` does not match U+0345).
- **Bounded**: one `Budget` per command (default 2^26 steps, `Session::set_find_budget`), charged by every instruction and
  every scan of the engine; the backtrack stack is capped at 2^18 entries. Out of budget, the command answers
  `budget: true` and changes nothing (F9-D1).
- **Prunes** (no result changes): the literal runs every match must contain bound the start positions
  (`Regex::scan_limit`); a pattern that starts with an unbounded `[^]*`/`[^]*?` stops scanning after its first failed start.
  They turn V8's exponential no-match searches into instant answers (F9-A1).

## Decisions outside the TS semantics (Opus)

| # | Decision | Why / evidence |
|---|---|---|
| F9-D1 | A find command has a step budget (2^26 by default) and a backtrack-stack cap (2^18); out of it the answer is `budget: true` (`FindOutcome`, `ReplaceOutcome.find`, `F9Result::Find` for select/highlight, `Err(Budget)` for `count_matches`) and nothing changes — except `replaceMatch`, whose replacement is done when only the search for the NEXT hit runs out (then the caret stays after the new text, the TS's not-found path) | the TS has no bound: catastrophic patterns hang the tab, and V8 loops forever on an empty match before an astral character (`lastIndex` steps back into the pair). The no-panic test measures every hostile shape |
| F9-D2 | The scan prunes (required literal runs, leading `[^]*`) | result-preserving; they make the common hostile no-match cases instant. Accepted difference F9-A1 below |
| F9-D3 | `goToSearchResult` of a stale result (the document changed since `search`) selects the stored positions as they are, as the TS (outside the story if the text shrank); the D2a ops answer `Position` there (D2a-T1) | faithful first; a clamp was tried and broke parity at the step itself |
| F9-D4 | `extraBase` is compared by value and context, not object identity; the two paths that make a new selection object with the same value without going through another family (undo/redo restore, `setSelection`) drop the extras explicitly | `Selection` is a value. Residual: another family assigning an equal selection keeps them (no case in the captures) |
| F9-D5 | `LangResolver`'s style memo is not kept: every lookup walks the `basedOn` chain (a style seen twice ends it) | identical on acyclic chains; with a cyclic chain the TS answer depends on which style was resolved first in the element's life |
| F9-D6 | `goTo('page' \| 'line')` answers `CommandError::NotPorted` (the layout's: the shell); headings and results carry no page | `eng.lines`/`currentPageOfCaret` are layout |
| F9-D7 | Any nesting depth compiles (explicit stacks); V8 reports "Stack overflow" past about 10^4 nested capture groups and "Too many captures" past 65,536 (ported) | measured on Node 24.15: 5,000 nested groups compile in V8, 20,000 do not |
| F9-D8 | The answers (`findNextMatch`'s `{ found, wrapped, error }`, booleans, counts) are `Session::navigation_result()` after `exec`; the query error is `QueryError` and its text is `QueryError::message(pt)` (`findMsg`: the shell knows the language) | D2a-Q1 (typed accessors), the paint and the language are the shell's |
| F9-D9 | `stylesEditable()` is always true | the session opens `.docx` and `.doc` only (the TS refuses for `.odt`) |
| F9-D10 | The story text indexes runs by a sorted `(start, para, run)` list instead of one entry per unit | memory (a 4.6 MB document would hold a 9 MB array per command); the same answers (`run_at`, identity by `(para, run)` for `^d`) |
